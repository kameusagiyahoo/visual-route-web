Visual Route Lab v5

V4が動いているGitHub Pagesへ、V5の5ファイルを上書きするだけです。

上書き: index.html / style.css / app.js / manifest.webmanifest / sw.js

1. V5で最初にやること

  1. 20歩キャリブレーション。
  2. 30〜60歩のルートを登録。
  3. 「画像系列キーフレーム」をONにする。
  4. 同じルートを最低5回ナビ。
  5. 各回、Photo/Turn/GOAL地点でGround Truthを押す。

2. Ground Truth

実際の既知地点 24歩 ↓ GT 推定MAP 21歩 ↓ 誤差 = |21 - 24| = 3歩 ↓ MAE / Median / P95へ集計

これはメートル測量の真値ではなく、「登録ルート上の既知歩数地点」です。

3. LOST判定

LOCALIZING ↓ LOCALIZED ← 強い画像再認識 ↓ UNCERTAIN ↓ 低信頼+方角不整合が継続 LOST ↓ 自動画像走査を高頻度化 LOCALIZED

LOSTでは誤った位置を確定表示せず「不明」とします。

4. 画像系列

V5は直近最大4回の画像候補について「ルート上でも同じ順番で進んでいるか」を加点します。単体で似た廊下があっても、A→B→Cの系列が違えば抑制できます。

5. 自動キーフレーム

登録中は初期5歩間隔で低解像度画像を端末内に保存します。DINOv2が読み込まれていればEmbeddingも保存します。写真枚数とSafariストレージは増えるため、長距離では8歩間隔も利用してください。

6. パラメータ学習

評価タブでGround Truthが5点以上になったら「GTから学習」を押します。

  • stepAdvance: 検出1歩あたりルート上でどれだけ進むか
  • heading σ: 方角誤差をどこまで許容するか
  • visual σ: 画像観測を何歩幅に広げるか

ルート選択時はそのルート専用、全ルート選択時はGlobal値を学習します。

7. Runtime Diagnostics

評価タブにMotion Hz、DINOv2推論時間、auto scan数を表示します。長時間利用時はAI inference P95が大きく増えるか確認してください。

8. Graph

V4のMNN/order検証に加え、V5は対応地点の前後anchor距離と局所turn signatureを比較します。「同じ見た目だが前後構造が違う場所」を統合しにくくします。

9. 推奨評価

  1. 同じルートを5回。
  2. 1走行3〜5個のGT。
  3. 合計20GT程度集める。
  4. 学習前のMAE/P95を記録。
  5. パラメータ学習。
  6. 再度5回走行し、MAE/P95を比較。
本質的制約: ARKit/SLAMではないため絶対座標(x,y,z)は出ません。V5の評価値は登録ルート上の相対位置精度です。
