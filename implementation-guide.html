Visual Route Lab v3

iPhone 15 / Safari / GitHub Pages / Mac・Xcode・Expo不要

既にV2が動いている場合
新しいリポジトリは不要です。ZIPの5ファイルを既存GitHub Pagesリポジトリのrootへ上書きCommitしてください。

1. 上書きするファイル

index.html style.css app.js manifest.webmanifest sw.js

README、CHANGELOG、TEST_CHECKLIST、implementation-guideはGitHubへ置かなくてもアプリは動きます。

2. 更新確認

  1. GitHubで5ファイルを上書きしてCommit。
  2. GitHub Pages URLをSafariで開く。
  3. ヘッダーが v3.0 になれば成功。
  4. 古い表示ならSafariで再読み込み。Service Workerはnetwork-firstで更新されます。

3. 最初に試す順番

  1. 「登録」→ センサー許可。
  2. 20歩キャリブレーション。
  3. 30〜60歩の短いルートを登録。
  4. START付近・曲がり角・GOAL付近でチェックポイント画像を撮る。
  5. 「ナビ」で同じSTARTから再走行。
  6. 「位置確率分布」が前方へ移動することを確認。

4. ベイズフィルタ

P(position=0..N) │ ├─ 1歩 → transition ├─ 方角 → heading likelihood ├─ turn → turn likelihood └─ image → checkpoint likelihood ↓ normalize ↓ MAP位置 + Confidence

V2のように補正値を直接足すのではなく、「どの地点にいる可能性が高いか」を分布として保持します。

5. AI画像Embedding

「MobileNetを読み込む」は任意です。押すとTensorFlow.jsとMobileNetV2 α0.25を外部CDN/モデル配信元から初回読み込みします。

状態挙動
AI未読込V2のRGB/edge/hash特徴で照合
AI読込成功MobileNet Embedding + V2特徴をハイブリッド
AI読込失敗自動でV2特徴へフォールバック
AIモデルは完全オフライン必須機能にはしていません。モデルを一度も読み込めない通信環境でも、ルート登録・ベイズナビは利用できます。

6. なぜV3はWebGPU推論ではないか

iOS 26 Safari自体はWebGPUを利用できる環境ですが、V3は実機安定性を優先し、TensorFlow.js MobileNetをWebGL backendで動かします。画面にはWebGPU availabilityだけ表示します。

WebGPU版は将来の実験機能として分離した方が、ナビ本体まで巻き込んで不安定になるのを避けられます。

7. ルートグラフ

最低2本のルートを登録し、同じ場所でチェックポイント写真を撮ってください。

Route A: 玄関 ─ [廊下📷] ─ リビング Route B: 寝室 ─ [廊下📷] ─ 洗面所 ↓ image cluster 共通Node「廊下」 ↓ Topological Route Graph
  1. 「グラフ」タブを開く。
  2. 可能ならAIモデルを読み込む。
  3. 「グラフを再構築」。
  4. 共通地点と判定されたNodeを確認。
  5. 出発Nodeと目的Nodeを選び「最短ルートを計算」。

8. 写真の撮り方

  • START/GOAL付近もできれば写真を撮る。
  • ドア枠、柱、固定棚、窓など動きにくい物を含める。
  • 壁だけ、床だけ、白い廊下だけを避ける。
  • 複数ルートで共通地点にしたい場所は、なるべく同じ向きで撮る。

9. V2データ

IndexedDBのV2データはそのまま読み込みます。削除や再登録は不要です。AI Embeddingがない旧写真は、AIモデル読込後に必要になった時点で遅延生成します。

10. 現時点の本質的制約

  • 絶対座標(x,y,z)は出ない。
  • 初見の建物では使えない。
  • 似た場所が連続すると画像だけでは識別困難。
  • Safariを閉じた状態で継続追跡はしない。
  • 歩数はiOS Pedometerではなく加速度推定。

11. V3評価

同じルートを5回歩き、以下を記録してください。

  • GOAL到達時のMAP推定歩数
  • GOAL時の信頼度
  • 位置確率分布が複数ピークになった場所
  • 画像観測前後のMAP位置
  • AIあり/なしの画像一致率
  • グラフで共通Nodeが正しく統合されたか
