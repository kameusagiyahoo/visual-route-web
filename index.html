仕様・課題

V5で対応した課題

  • 精度を測れない → Ground Truth記録とMAE / Median / P95 / GOAL成功率を追加
  • 常にどこかを返す → LOCALIZED / UNCERTAIN / LOST状態機械を追加
  • 画像1枚のPlace Recognition → 直近最大4フレームの時系列整合を追加
  • 登録画像が疎い → ルート記録中の自動キーフレームを追加
  • ベイズ係数が固定 → GT履歴からstep advance / heading σ / visual σを自動学習
  • Graph誤結合 → 前後anchor距離と局所turn signatureの文脈検証を追加
  • 負荷が見えない → Motion Hz / AI推論時間 / scan数等のRuntime Diagnosticsを追加
  • V4のAdaptive Step / Gyro turn / DINOv2 / Bayesian Filter / 自動再ローカライズを継承

残る制約

ARKit/SLAMではないため絶対座標(x,y,z)は出ません。V5は曖昧なときにLOSTを返せるようにしましたが、反復廊下・大きな視点差・カメラ遮蔽では再ローカライズできない場合があります。評価値は登録ルート上の「歩数地点」を真値とした相対誤差であり、メートル測量精度ではありません。
